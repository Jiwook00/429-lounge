# Sparkle로 앱 안에서 업데이트 설치

[ADR-0010](0010-update-notice-min-version.md)의 업데이트 안내는 새 버전을 알려 준다. 설치하려면 회원이 명령을 복사해 터미널을 열어야 했다.

Sparkle을 배포용 앱에 연결한다. 회원이 라운지의 업데이트 카드에서 설치를 선택하면 Sparkle이 최신 버전을 확인하고, 서명을 검증한 뒤 앱을 교체하고 다시 연다. 게임을 하는 도중 앱이 재시작하지 않도록 자동 설치는 비활성화한다. 기존 수동 설치와 서버 최소 버전은 유지한다.

- GitHub의 최신 정식 릴리스에 appcast와 ZIP을 함께 올린다. appcast는 버전별 ZIP 주소를 가리킨다.
- Sparkle의 EdDSA 키로 피드와 ZIP을 서명한다. ZIP은 추출 전에 검증한다. 첫 공개키는 이후 배포에서도 유지하고, 비공개 키의 복구용 사본을 보관한다.
- 번들 버전은 앱 버전과 동일한 값을 쓴다. 기존 회원은 Sparkle을 포함한 배포본을 한 번 수동 설치해야 한다.
- 배포본은 베타의 ad-hoc 서명을 사용한다. 앱을 처음 실행하거나 교체할 때 macOS가 확인을 요청할 수 있다.
