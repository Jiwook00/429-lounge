# 칩 경제 v1

구현: `supabase/migrations/*_chip_economy.sql`. 지급은 전부 서버 함수에서, 클라이언트는 로컬 로그 수치만 보낸다.

## 원칙

- **요금제 차이는 인정한다.** 토큰을 많이 쓰는 사람(Max 등)이 칩을 더 받는다. 대신 칩은 실력(과 운)으로 따면 된다.
- **칩은 현금·실물·선물로 바꿀 수 없다.** 칩끼리 주고받는 기능도 없다. 사행성 선을 넘지 않기 위한 고정 규칙.
- **소규모 회원제 라운지라 클라이언트를 신뢰한다.** 서버는 "말이 되는지"(날짜 범위, 상한, 리셋 시각)만 검사.

## 수입

| 항목      | 규칙                                                                                               | 중복 방지                                                                |
| --------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 시작 지갑 | 1,000칩                                                                                            | 플레이어 생성 시 1회                                                     |
| 토큰 환전 | fresh 토큰(입력+출력+캐시 쓰기, 캐시 읽기 제외) 1,000개 = 1칩. 상한 없음. Claude Code + Codex 합산 | 날짜별 "지금까지 지급한 칩"을 저장하고 차액만 지급. 30초마다 보내도 안전 |
| 오늘의 칩 | 잔액 옆 `오늘의 칩 받기`로 하루(KST) 한 번 +100칩. 누를 때 잔액이 100칩 미만이면 +300칩            | `players.last_daily`                                                     |
| 황금 칩   | 429에 걸리면 5시간 리밋 3개, 주간 리밋 10개. 도구마다 따로 (ADR-0009)                              | 리밋 한 건(`resets_at`)당 1회                                            |

토큰은 캐시 읽기를 뺀다. 양이 압도적으로 많고(fresh의 10배 안팎) 실제 작업량과 비례하지 않아서.

한국 시간 자정이 지나면 잔액 옆에 버튼이 다시 나타난다. 받으면 버튼이 사라진다.

### Codex

- 로그: `~/.codex/sessions/**/*.jsonl` (`CODEX_HOME`). 응답마다 남는 `token_usage_record`를 `response_id`로 센다
- Codex의 `input_tokens`는 캐시를 포함한다 → fresh = `input_tokens − cached_input_tokens + output_tokens` (reasoning은 output 안에 있음)
- 429: `rate_limits`의 창이 가득 차면(`used_percent` ≥ 100) 그 창의 `resets_at`. 창 300분 = `five_hour`, 10080분 = `seven_day`, 그 외는 10개
- 실제 429 로그로는 아직 확인 못 함

## 황금 칩

- 1개 = **공짜 100칩 베팅**. 이기면 200칩, 지면 아무것도 잃지 않음
- **리셋 시각에 소멸.** 코딩을 못 하는 그 시간 동안 쓰라고 주는 보너스
- 이전 황금 칩이 만료된 상태에서 새로 받으면 0부터 다시 시작

## 서버 검사

| RPC                             | 거절 조건                                          |
| ------------------------------- | -------------------------------------------------- |
| `claim_tokens(day, fresh)`      | day가 KST 오늘 ±1일 밖 / fresh < 0 또는 5천만 초과 |
| `claim_golden(resets_at, type)` | 이미 지난 리셋 / 8일보다 먼 리셋                   |
| `slot_spin(amount, golden)`     | 일반 칩 1~200 범위 밖 / 잔액 부족 / 황금 칩 없음   |
| `oddeven_bet(...)`              | 늘 거절(`game_retired`). 홀짝은 은퇴 (ADR-0015)    |

## 게임별 배당

### 미니 룰렛 (ADR-0015)

0~12, 13칸. 빨강 1 4 5 8 9 12, 나머지 1~12는 검정, 0은 초록. 첫 베팅이 12초 판을 열고(혼자면 바로 돌리기), 마감 → 회전 6초 → 결과 4초.
칸을 누르면 바로 걸린다. 같은 칸에 또 걸면 더해지고, 건 칩은 취소할 수 없다. 칩 단위 10 · 50 · 100, 기본값 10칩. **판당 상한 없음**(일반 칩·황금 칩 모두, 실제 플레이를 보고 정한다).

| 칸                                   | 칸 수 | 지급 (건 칩 포함) |
| ------------------------------------ | ----- | ----------------- |
| 숫자 하나 (1~12)                     | 1     | ×12               |
| 빨강·검정 / 홀·짝 / 1–6·7–12         | 6     | ×2                |
| 0이 나오면 (무효 판, 0엔 걸 수 없음) | -     | 모든 칸 ×1        |

환수율은 모든 칸이 **100%** (예: 숫자 하나 = 1/13 × 12 + 1/13 × 1). 하우스 몫이 없어서 은퇴한 홀짝의 칩 흐름을 그대로 이어받는다. 수치는 SQL로 13개 결과를 모두 계산해 확인 (`roulette_multiplier`).

| 경우                                      | 처리                                         |
| ----------------------------------------- | -------------------------------------------- |
| 일반 칩: 빨강에 50, 9(빨강)               | 100 지급, 순수익 +50                         |
| 일반 칩: 7에 50 + 빨강에 50, 7(검정)      | 600 + 0 지급, 순수익 +500                    |
| 일반 칩: 어디든, 0                        | 건 칩 그대로 돌려줌, 순수익 0                |
| 황금 칩: 검정에 1개, 검정                 | 200 지급, 순수익 +200                        |
| 황금 칩: 검정에 1개, 빨강                 | 0, 잃는 칩 없음                              |
| 황금 칩: 검정에 1개, 0                    | 칩 대신 황금 칩 1개를 돌려줌(아직 유효할 때) |
| 마감 뒤 ~ 결과 연출 끝(10초) 안에 온 베팅 | `betting_closed`로 거절, 칩 그대로           |

한 판 지급 합계가 1,000칩 이상이면서 이득이면 전광판 빅 윈. 이번 주 큰손 순수익은 칸마다 `지급 − 건 칩`(황금 칩은 0).

| RPC                                        | 거절 조건                                                                                                                                |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `roulette_bet(room, spot, amount, golden)` | 닉네임 없음 / 마감(`betting_closed`) / 없는 칸·0(`invalid_spot`) / 황금 칩을 숫자 칸에(`golden_outside_only`) / 잔액 부족 / 황금 칩 없음 |
| `roulette_spin(room)`                      | 베팅 중 아님 / 안 걸음(`not_seated`) / 다른 회원도 걸음(`not_alone`)                                                                     |

### 구슬 홀짝 (은퇴)

맞히면 건 금액의 2배였다(하우스 엣지 없음). 미니 룰렛의 홀·짝 칸이 같은 게임이라 은퇴했다. 지난 기록은 이번 주 큰손에 그대로 남는다.

### 429 슬롯

릴 3개 × 가운데 한 줄. 릴 한 바퀴 26칸: 체리 6, 벨 5, BAR 4, 7 3, 429 1, 빈칸 5, 500 2.
일반 칩 단위는 10 · 50 · 100 · 200칩이고 기본값은 50칩. 서버 상한은 한 번에 200칩.

| 결과          | 배수                                  |
| ------------- | ------------------------------------- |
| 429 429 429   | ×429 (잭팟)                           |
| 7 7 7         | ×50                                   |
| BAR BAR BAR   | ×20                                   |
| 벨 ×3         | ×10                                   |
| 체리 ×3       | ×5                                    |
| 체리 2개      | ×3                                    |
| 429 둘 / 하나 | ×3 / 일반 ×1.8, VIP·황금 칩 ×1 (본전) |

| 기믹                          | 행동                                                                              |
| ----------------------------- | --------------------------------------------------------------------------------- |
| **500 Internal Server Error** | 처음 멈춘 릴에 뜨면 그 릴만 다시 돈다. 다시 돌 땐 500이 안 나와서 환수율은 그대로 |
| **VIP HOUR**                  | 황금 칩 유효 시간(= 429 리셋 전)엔 릴에 429와 빈칸이 한 칸씩 더 (28칸)            |

|               | 평소        | VIP HOUR |
| ------------- | ----------- | -------- |
| 환수율        | 101.93%     | 107.97%  |
| 지급 확률     | 28.4%       | 34.9%    |
| 잭팟          | 1/13,824    | 1/2,197  |
| 글리치 리스핀 | 판의 약 21% | 약 20%   |

환수율은 앱의 베팅 단위 기준이다. 배수는 건 금액을 포함하고 소수 칩은 버린다. 429 하나와 체리 두 개가 함께 나오면 체리 두 개 배당(×3)을 적용한다. 일반 칩을 건 평소 슬롯은 28.39%의 판에서 순이익이 난다. 황금 칩 스핀은 100칩짜리 공짜 스핀이다.

200 와일드와 404 심볼은 한때 넣었다가 기믹이 너무 많아져서 뺐다 (응답 라인의 `404 Not Found`는 꽝 표시로 남음).

### 소수결 (ADR-0013)

평일(KST) 8·11·14시에 질문이 열리고 3시간 뒤 정산. 둘 중 하나에 **50칩**을 걸면 적게 고른 쪽이 이긴다. 참가비는 판을 열 때 정하며, 변경 전에 열린 판에는 기존 참가비가 적용된다.

| 경우                             | 정산                                          |
| -------------------------------- | --------------------------------------------- |
| 참가 3명 미만 / 동점 / 전원 일치 | 무효, 각자 걸었던 칩 그대로 돌려줌            |
| 그 외                            | 소수 쪽이 진 사람이 건 칩을 똑같이 나눔(내림) |

예: 3명 중 2 대 1이면 혼자 고른 사람이 150칩을 받는다(+100). 하우스 몫은 없다.

| RPC                     | 거절 조건                                                                          |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `minority_pick(choice)` | 닉네임 없음(`not_named`) / 열린 판 없음(`minority_closed`) / 이미 고름 / 잔액 부족 |

### 블랙잭 (ADR-0014)

딜러와 겨룬다. 히트 / 스탠드 / 더블다운(첫 두 장)만, 스플릿·인슈어런스 없음. 무한 덱, 딜러는 17 이상 멈춤(소프트 17 포함), 홀 카드 없음(딜러가 블랙잭이면 더블한 칩도 짐).
베팅 10 · 30 · 50 · 100, 기본값 30칩. 황금 칩(100칩 공짜) 가능. 빈 자리의 AI 봇은 칩이 없다.

| 결과                 | 지급 (건 칩 포함)                                                         |
| -------------------- | ------------------------------------------------------------------------- |
| 블랙잭 (첫 두 장 21) | 일반 칩 × 2.75, 황금 칩 × 2.5. 소수 칩은 버린다. 딜러도 블랙잭이면 무승부 |
| 이김 / 딜러 버스트   | 건 칩 × 2 (더블이면 두 배 건 칩 × 2)                                      |
| 무승부               | 건 칩 그대로. 황금 칩이면 칩 대신 황금 칩 1개 반환                        |
| 짐 / 버스트          | 0                                                                         |

|                               | 환수율 |
| ----------------------------- | ------ |
| 패치 전 최적 전략             | 98.83% |
| 더블 없이 (황금 칩 판)        | 97.58% |
| 패치 전 딜러처럼 16 이하 히트 | 94.33% |

같은 플레이 전략에서 일반 칩 내추럴 상향분은 최초 베팅액 대비 약 0.90~1.13%p다. 범위는 칩 단위 내림에 따른 베팅액별 차이다. 지급 1,000칩 이상이면 전광판 빅 윈.

| RPC                                 | 거절 조건                                                                                             |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `bj_bet(room, amount, golden)`      | 닉네임 없음 / 베팅 마감(`betting_closed`) / 이미 앉음 / 만석(`table_full`) / 잔액 부족 / 황금 칩 없음 |
| `bj_deal(room)`                     | 베팅 중 아님 / 안 앉음(`not_seated`) / 다른 회원도 앉음(`not_alone`)                                  |
| `bj_action(room, hit·stand·double)` | 내 차례 아님(`not_your_turn`) / 더블은 첫 두 장·황금 칩 아님·잔액 있을 때만(`cannot_double`)          |

### 429 드롭 (ADR-0018)

12줄 격자 플링코. 공 하나 = `plinko_drop` 한 번, 일반 칩 1~300(칩 단위 50 · 100 · 200 · 300, 기본값 50칩), 황금 칩은 100칩 공짜 공 1개. 동시에 최대 5개.
배수는 건 칩을 포함하고 소수 칩은 버린다. 수치의 원본은 `scripts/drop_ev.py`이고 서버 함수와 같이 고친다.

| 칸 (왼쪽부터) | 1   | 2   | 3    | 4    | 5    | 6    | 7 (가운데) | 8    | 9    | 10   | 11   | 12  | 13  |
| ------------- | --- | --- | ---- | ---- | ---- | ---- | ---------- | ---- | ---- | ---- | ---- | --- | --- |
| 배수          | ×16 | ×4  | ×1.8 | ×1.3 | ×1.0 | ×0.6 | ×0.4       | ×0.6 | ×1.0 | ×1.3 | ×1.8 | ×4  | ×16 |

| 특수 핀     | 위치 (줄, 칸)        | 효과                                                                                   |
| ----------- | -------------------- | -------------------------------------------------------------------------------------- |
| 가이드      | (0, ±2) 옆 레인 입구 | 공을 안쪽으로 민다. 그래서 세 레인의 기대값이 같다                                     |
| 골드        | (8, ±4)              | 맞은 공의 최종 배수 +0.3 (분열한 공은 둘 다)                                           |
| 분열        | (10, ±8)             | 공이 둘로, 둘 다 같은 건 칩으로 지급. 공 하나당 한 번, FEVER 공은 분열 없음            |
| 스타트 포켓 | (6, 0)               | 등급별 확률로 공을 잡는다. 잡히면 1/8로 FEVER(공 15개, 배수 ×2), 아니면 건 칩 20% 환급 |

게이지 24칸에서 뗀 칸으로 등급이 정해진다(서버가 파워 0~1000으로 판정). 가운데 1칸 PERFECT, 양옆 2칸씩 GOOD. 등급은 포켓이 공을 잡을 확률만 올린다.

| 등급             | 포켓이 잡을 확률 | 환수율 (세 레인 모두) |
| ---------------- | ---------------- | --------------------- |
| 기본             | 9.47%            | 98.00%                |
| GOOD             | 10.08%           | 98.50%                |
| PERFECT          | 10.68%           | 99.00%                |
| AUTO (랜덤 파워) | -                | 약 98.13%             |

공 하나 기준: 순이익 약 24%, 골드 핀 약 23%, ×4 이상 약 1/90, 분열 약 1/50, 포켓 약 1/34, FEVER 약 1/280(평균 약 25배), ×16 약 1/2,000. FEVER가 환수율의 약 8%p라 짧게 보면 분산이 크다. 실제 데이터를 보고 조정한다.

| RPC                                        | 거절 조건                                                                                                         |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `plinko_drop(amount, lane, power, golden)` | 닉네임 없음(`not_named`) / 1~300 밖(`invalid_amount`) / 잔액 부족 / 황금 칩 없음. 레인(-1~1)·파워(0~1000)는 clamp |

전광판 빅 윈: FEVER로 1,000칩 이상, 또는 ×16 끝 칸이면서 500칩 이상.

### 럭키 드로우

무료 티켓은 KST 하루 3장까지다. 처음 긁을 때 수령하고, 같은 날 다음 장은 직전 수령으로부터 2시간 뒤에 열린다. 날짜가 바뀌면 첫 장을 바로 받을 수 있다. 금액과 지갑 지급은 서버가 결정한다. 같은 날짜와 회차의 재요청은 기존 결과를 반환한다.

| 지급액 | 100칩 | 200칩 | 50칩 | 300칩 | 429칩 |
| ------ | ----: | ----: | ---: | ----: | ----: |
| 확률   |   36% |   27% |  15% |   12% |   10% |

기댓값은 장당 176.4칩이다. 티켓 기록은 주간 게임 순수익 집계에서 제외한다.
